YOUR SERVICE ACCOUNTS

Accounts

Manage sign-in separately for each self-hosted service.

♫

Navidrome account

Users and permissions are managed by Navidrome.

Open the local music server to sign in, create its first administrator, or manage additional users. SyncPulse never signs in for you; the optional account in Settings is used only to request a library rescan.

▶

Invidious account

Subscriptions and preferences are managed by Invidious.

Open the local Invidious instance to sign in or manage its account. Invidious registration availability depends on the server configuration.

One login everywhere is not enabled.

Navidrome and Invidious have independent authentication. A single sign-on needs a compatible identity provider and explicit configuration for both services; SyncPulse does not claim to synchronize credentials.

This preference alone does not publish anything. The Tailscale one-click button below asks for confirmation before making the artwork listener public. Without a public artwork URL, Discord uses the integration’s default Navidrome artwork icon.

i

Where to get this address: With Navidrome, enter the HTTPS address you already use to open Navidrome from outside your home. With Private cover server, first publish the shown loopback listener using Tailscale Funnel or a Cloudflare Tunnel, then enter that tunnel's public HTTPS hostname. For Funnel, use the machine's .ts.net address and the HTTPS port configured below (for example, https://my-pc.example-tailnet.ts.net:8443). For Cloudflare, use the public hostname you assign to the tunnel and route it to the cover listener. Enter only the origin (scheme, hostname, optional port), without a path or trailing slash. SyncPulse never creates a public tunnel automatically.

ⓘ

In server mode SyncPulse starts an image-only server bound to loopback; it never starts a public tunnel for you. Publish only that port using Tailscale Funnel or your reverse proxy. Funnel makes its selected port public (not just the image path), so avoid ports already used by Tailscale Serve.

Tailscale Funnel allows ports 443, 8443, and 10000.
tailscale funnel --bg --https=8443 http://127.0.0.1:4534
